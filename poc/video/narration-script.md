# Prompt to Production: narration

What the voiceover says, and when. Spellings like "Jeera" and "Co-pah-do" are phonetic so the generated voice pronounces them correctly; read them normally if you record your own voice.

|---|---|
| 0:00.0 | Hi everyone. Let me show you how this works. |
| 0:04.9 | So, here's our Tech Lead, in Codex. One request, typed in plain English. When a provider account is approved, create its Healthcare Facility Network record, and notify the network manager. That's it. That's the only input anyone gives. |
| 0:28.9 | Before anything gets built, the Impact and Reuse agent checks the knowledge graph. And it turns out, this already exists, in Apex, and in Flow. So the advice is simple. Extend what's there. Don't add a third path. |
| 0:44.5 | Now, a person decides. The P M and Tech Lead see the same evidence, and approve the scope. |

| 1:06.0 | Next, the Architect agent picks the pattern from facts, not habit. And the Confluence agent publishes the solution design. |
| 1:18.3 | The Tech Lead signs off the design, before a single line of code is written. |
| 1:26.7 | Now the Developer agent writes the change, to Ascension's standards. The Review agent checks it, and only then is a pull request opened. |
| 1:40.6 | The Tech Lead approves the pull request. Agents never approve their own work. |

| 2:13.2 | Production stays with your existing change advisory board. They approve, and then it goes live. |
